Launch Radar ranks pre-token DefiLlama protocols by an implied launch value from sealed snapshot figures (category mcap/TVL comps, 7d growth, age without a token, chain breadth) and ships a static farm-plan dashboard.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node --experimental-strip-types main.ts --input /path/to/snapshot.json
open out/dashboard/index.html
```
